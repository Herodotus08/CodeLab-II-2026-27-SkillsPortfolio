# 03 - Student Manager

A Tkinter student marks manager backed by `../A1 - Resources/studentMarks.txt`.

## Menu Options Included
1. View all student records (with student count and class average percentage)
2. View individual student record (search by name or 4-digit student code)
3. Show student with highest total score
4. Show student with lowest total score
5. Sort student records (ascending or descending)
6. Add a student record (saved to `studentMarks.txt`)
7. Delete a student record (saved to `studentMarks.txt`)
8. Update a student's record via field sub-menu (saved to `studentMarks.txt`)

## Run
```bash
python student_manager.py
python -m unittest test_student_manager.py -v
```
