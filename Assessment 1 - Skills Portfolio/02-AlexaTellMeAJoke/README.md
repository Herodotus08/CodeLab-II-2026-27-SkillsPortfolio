# 02 - Alexa tell me a Joke

A Tkinter joke assistant that reads jokes from `../A1 - Resources/randomJokes.txt`, shows the setup first, reveals the punchline on click, avoids repeats with a shuffled deck, and supports keyword filtering and favourites.

## Run
```bash
python alexa_joke.py
python -m unittest test_alexa_joke.py -v
```
