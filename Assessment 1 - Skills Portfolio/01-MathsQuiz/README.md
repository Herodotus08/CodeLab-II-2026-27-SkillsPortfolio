# 01 - Maths Quiz

A Tkinter arithmetic quiz with three difficulty levels (Easy, Moderate, Advanced), 10 random addition/subtraction questions per round, two attempts per question (10 points on first try, 5 on second), progress tracking, saved best scores, and an end-of-quiz answer review.

## Run
```bash
python maths_quiz.py
python -m unittest test_maths_quiz.py -v
```
